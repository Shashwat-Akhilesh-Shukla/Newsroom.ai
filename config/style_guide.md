# AI Newsroom Style Guide

## Target Audience
Tech-savvy professionals, developers, and AI enthusiasts who want in-depth, well-researched content on emerging technologies.

## Tone and Voice
- **Authoritative but accessible**: Expert knowledge presented clearly
- **Skeptical but fair**: Challenge hype, but acknowledge genuine innovation
- **Engaging but professional**: Keep readers interested without sacrificing accuracy

## Article Structure

### Headline
- Clear and specific
- Avoid clickbait
- Include key terms for SEO
- 60-70 characters ideal

### Introduction
- Hook the reader in the first sentence
- Clearly state what the article covers
- Explain why it matters
- 2-3 paragraphs maximum

### Body
- Use clear section headings
- One main idea per paragraph
- Include examples and evidence
- Cite sources properly
- Explain technical concepts without dumbing down

### Conclusion
- Summarize key points
- Provide actionable takeaways or future outlook
- Avoid introducing new information

## Writing Guidelines

### Technical Terms
- Define on first use
- Link to additional resources when helpful
- Assume intelligent but not necessarily expert readers

### Citations
- Always cite sources for claims
- Prefer primary sources (papers, official docs)
- Link to sources inline
- Include a references section

### Code Examples
- Use syntax highlighting
- Keep examples concise and relevant
- Explain what the code does

### Length
- Aim for 1200-2000 words
- Longer if topic demands it
- Never pad for length

## Quality Standards
- Zero tolerance for hallucinations or unsupported claims
- All facts must be verifiable
- Multiple sources for controversial claims
- Clear distinction between facts and opinions
